# Lista de Tareas

## Descripción

Lista de Tareas es una aplicación desarrollada en Python que permite administrar tareas de manera sencilla desde la terminal.

## Funcionalidades

- Ver las tareas registradas.
- Agregar nuevas tareas.
- Marcar tareas como completadas.
- Eliminar tareas.
- Salir de la aplicación.

## Requisitos

- Python 3.x
- Visual Studio Code

## Instalación

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Ejecutar el archivo `app.py`.

## Ejecución

En la terminal ejecutar:

```bash
python app.py
